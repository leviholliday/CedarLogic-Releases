# CedarLogic 4 downloads

Installers for CedarLogic 4, a digital logic simulator for Mac and Windows. The redesign was done by Claude, Anthropic's AI model. It builds on [Kieran Klukas's modernized CedarLogic](https://github.com/taciturnaxolotl/CedarLogic) and on the original from Cedarville University.

Get the latest version from [Releases](../../releases/latest).

- **Mac:** `CedarLogic-<version>-mac.dmg`. Drag the app into Applications.
- **Mac, the native app (beta):** `CedarLogic-Native-<version>-mac.dmg` (see the CedarLogic Native releases). Drag it into Applications; the first time, right-click it and choose Open.
- **Windows:** `CedarLogic-<version>-win32.exe`. If Windows says it protected your PC, choose More info, then Run anyway.

Found a bug? [Open an issue](../../issues/new).

`appcast.xml` is the update feed the app reads. It lists no updates until the first signed release is published.
